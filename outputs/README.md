# Outputs

This folder contains the main outputs generated during the project.

## Folder structure

- `tables/`  
  Processed CSV tables, summaries and final ranking results.

- `figures/`  
  Charts generated with Python.

- `maps/`  
  Final maps produced in QGIS.

## Main outputs

The main results include:

- summary of antimony-related ARDF occurrences;
- distribution of sites by type;
- historical production status;
- consolidated antimony grades and tonnages;
- stream-sediment antimony statistics;
- moderate, high and very high geochemical anomalies;
- geochemical support assigned to the 13 documented sites;
- final multicriteria ranking;
- final ranking chart;
- four thematic maps.

## Main maps

1. Distribution of antimony occurrences in Alaska;
2. Historical antimony grades at documented sites;
3. Stream-sediment antimony anomalies;
4. Final antimony exploration priorities.

## Reproducibility

Most tabular outputs and figures can be reproduced using the scripts stored in the `scripts/` folder.

The maps were produced in QGIS using the processed data, USGS geological layers and an OpenStreetMap basemap.
