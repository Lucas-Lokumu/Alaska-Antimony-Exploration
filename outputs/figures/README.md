# Figures

This folder contains figures generated with Python.

## Main figure

The principal figure presents the final multicriteria ranking of the 13 documented antimony sites in Alaska.

The ranking combines:

- the site screening score;
- the geochemical score;
- the final priority class.

The figure distinguishes:

- high-priority sites;
- medium-priority sites;
- low-priority sites.
