# Maps

This folder contains the thematic maps produced in QGIS.

## Maps included

1. Distribution of antimony occurrences in Alaska;
2. Historical antimony grades at documented sites;
3. Stream-sediment antimony anomalies;
4. Final antimony exploration priorities.

## Data sources

The maps combine data from:

- USGS Alaska Resource Data File;
- USGS Alaska Geochemical Database Version 4.0;
- USGS Geologic Map of Alaska, Scientific Investigations Map 3340;
- OpenStreetMap.

## Interpretation

The maps are exploratory visual outputs.

They do not constitute:

- a mineral resource estimate;
- a reserve estimate;
- a field-based geological validation;
- an economic assessment.

The geological layer is used as regional descriptive context and is not directly included as a weighted component of the final score.
