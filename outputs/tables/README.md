# Tables

This folder contains the main processed tables and CSV outputs generated during the project.

## Main files

The folder may include:

- filtered antimony occurrences from the ARDF database;
- summaries of site types and production status;
- consolidated historical grades and tonnages;
- stream-sediment antimony statistics;
- exported geochemical anomalies;
- site-level screening scores;
- geochemical support scores;
- final multicriteria ranking.

## Important note

Only processed and lightweight files are stored in this repository.

Large raw USGS datasets are not included. See `data/README.md` for the official data sources.
