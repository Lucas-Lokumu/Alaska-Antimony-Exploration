# Data

This folder contains information about the datasets used in the project.

Large raw datasets are not stored directly in this repository.

## Main data sources

- USGS Alaska Resource Data File (ARDF)
- USGS Alaska Geochemical Database Version 4.0 (AGDB4)
- USGS Geologic Map of Alaska, Scientific Investigations Map 3340
- OpenStreetMap

## Folder structure

- `raw/`: original datasets downloaded from official sources
- `processed/`: cleaned and processed datasets generated by the Python scripts
