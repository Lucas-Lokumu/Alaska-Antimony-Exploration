# Report

This folder contains the final project reports.

## Main document

**Évaluation multicritère du potentiel d'exploration de l'antimoine en Alaska**

The reports presents a multicriteria assessment of antimony exploration potential in Alaska by combining:

- historical mineral occurrences from the Alaska Resource Data File;
- documented antimony grades and tonnages;
- stream-sediment geochemical anomalies from AGDB4;
- regional geological context;
- Python-based data processing;
- QGIS spatial analysis and mapping.

## Reports structure

The reports includes:

1. study context;
2. data sources;
3. data preparation;
4. multicriteria methodology;
5. results;
6. discussion;
7. recommendations;
8. limitations;
9. conclusion;
10. bibliography and appendices.

## Language

The full report is written in French and English.

## Important interpretation note

The final ranking is an exploratory screening tool.

It does not constitute:

- a mineral resource estimate;
- a mineral reserve estimate;
- a feasibility study;
- an economic assessment;
- a field-based geological validation.

The results are intended to identify sites that may justify further documentary, geological or geochemical investigation.
